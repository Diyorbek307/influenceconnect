# InfluenceConnect

Платформа, соединяющая **бренды** и **блогеров** для рекламных коллабораций —
в формате свайпов (как Tinder). Собрано на **Flutter** (мобайл + web).

## Роли и возможности

| Роль | Что умеет |
|------|-----------|
| **Бренд** | Свайпает блогеров, создаёт и ведёт рекламные кампании, видит отклики и совпадения, редактирует профиль |
| **Блогер** | Свайпает кампании и откликается, видит интерес брендов и совпадения, заполняет профиль (охват, ниша, ER) |
| **Админ** | Дашборд с метриками, управление пользователями (блок/разблок/удаление), модерация кампаний |

## Демо-аккаунты

Пароль у всех демо-аккаунтов: `demo1234` (у админа — `admin123`).

| Роль | Email | Пароль |
|------|-------|--------|
| Админ | `admin@influence.app` | `admin123` |
| Бренд | `glow@demo.app` | `demo1234` |
| Блогер | `anna@demo.app` | `demo1234` |

На экране входа есть кнопки **быстрого входа** для каждой роли.
Чтобы сделать админом нового пользователя — при регистрации введите
код-приглашение `INFLUENCE-ADMIN`.

## Архитектура

```
lib/
  main.dart                 — точка входа
  theme/                    — цвета и темы (светлая/тёмная)
  models/                   — Profile, Campaign, Swipe
  data/
    app_repository.dart     — локальный бэкенд (ChangeNotifier + SharedPreferences)
    seed_data.dart          — демо-наполнение «базы» (блогеры/бренды/кампании)
    constants.dart          — справочники ниш и платформ
  widgets/                  — переиспользуемые компоненты (свайп-колода, карточки…)
  screens/
    auth/                   — вход/регистрация
    brand/                  — панель бренда
    blogger/                — панель блогера
    admin/                  — панель администратора
    shared/                 — профиль (общий)
  utils/                    — вспомогательные расширения
```

**Данные.** Сейчас приложение работает на локальном бэкенде
(`AppRepository` + `SharedPreferences`) — запускается сразу, без сервера,
с демо-наполнением. Вся логика изолирована в одном классе-репозитории, поэтому
переход на реальную общую БД (**Supabase**) сводится к замене реализации методов.
Готовая SQL-схема лежит в [`supabase_schema.sql`](supabase_schema.sql),
пошаговая инструкция — в [`DEPLOY.md`](DEPLOY.md).
